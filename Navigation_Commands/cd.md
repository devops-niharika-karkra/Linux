# Command: cd
## cd: Change Directory

This command is used to navigate from one directory to another. 
It is used in many ways which are listed below:

#### cd: helps to return in user's home directory
```
  cmd:
      cd
```

#### cd <directory_name>: It is used to switch a directory
```
  cmd:
      cd <directory_name> 
```

#### Absolute path: It is used to go to the destination from root folder.
```
  cmd:
      cd /path/to/directory
```

#### Relative path: It is used to go to another directory from the current location.
```
  cmd:
      cd ../sibling_directory
```

#### cd - : helps to return to our previous working location. 
```
  cmd:
      cd -
```

#### cd .. : help us to return out of one directory at a time. 
```
  cmd:
      cd ..
```

#### cd ~: help us to go back to user's home directory.
```
  cmd:
      cd ~
```
