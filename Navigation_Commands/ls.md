# Command: ls

This command is used to list all the files and directories present in specified path.

## Use-Cases of ls:

### To display list of items in directory
```
  ls
```

### To display list of items of specified path
```
  ls /path/to/directory/
```

### To display list with all details
```
  ls -l
```

### To display list of items in human readable form
```
  ls -h
```

### To display list of items according to time 
```
  ls -t
```

### To display list files in reverse order
```
  ls -r 
```

### To display list of files in single line
```
ls -1
```

### To display list of files present in parent directory of current directory
```
  ls ..
```
