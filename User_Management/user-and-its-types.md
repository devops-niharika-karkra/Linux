# What is a User in Linux?
  - User is a system entity that can login and access the system. Each user has its own identity, permissions, and access privileges.
  - One of the best practices of users in Linux is that each person working on a system should have their own individual user account as Linux supports multiple users and allows multiple users to log in to the system simultaneously.
  - Having separate users accounts provide better security, access control and accountability.

## Types of users:

  - **Root User**: It is the super user. It has all the controls.
  - **Regular user**: It is the normal user with limited access.
  - **System user**: User created by system for running services.
  - **Sudo user**: Regular user with temporary user rights.
  - **Guest user**: Temporary users with minimal privileges
