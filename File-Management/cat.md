# Command: cat

***cat*** stands for concatenate which means joining multiple items together. 
This command is used to view, create and combine file content directly from terminal.

### The basic syntax is:
```
  cat [OPTION] [file]
```

### To display file content
```
  cat <filename>
```

### To diplay content of file using its path
```
  cat /path/to/filename
```

### To display the content of multiple files in linux
```
  cat <file1> <file2> <file3>
```

### To add content in file.
```
  cat >> <filename>
```
  Ctrl + d -> Save and Exit

### To merge the content of files 
```
  cat <file1> <file2> > <newfile>
```
