# Command: rm
***rm*** stands for remove. Using this we can remove or delete files and directories. 

### Basic Syntax
```
  rm [Option] [filename]
```
## Use-Cases of rm 

### To remove a file or directory 

```
  rm <file or directory name>
```

### To remove multiple files

```
  rm <file1> <file2> <file3>
```

### To take the user confirmation before deleting any file

```
  rm -i <filename>
```

### To get the output of what is being done

```
  rm -v <filename>
```

### To delete a directory and its content recursively

```
  rm -r <dir-name>
```

### To delete an item forcefully 

```
  rm -f <file_name>
```
